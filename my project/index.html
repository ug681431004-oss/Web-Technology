    How it's structured

    Underneath the game sits a simple relational design — every word is one row, linked to its translations and its category.

    1. Languages

      Reference table: code, name, script direction (ltr / rtl).

    2. Categories

      Groups of vocabulary — greetings, numbers, colors, animals.

    3. Words

      One entry per concept, foreign-keyed to its category.

    4. Translations

      One row per word × language, so any pair can be matched.
